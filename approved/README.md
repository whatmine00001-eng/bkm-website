# Утверждённая политика БКМ для включения лидов

По умолчанию **онлайн-заявки в Bitrix24 НЕ включаются**. Сайт использует связь по email/телефону. Черновик `privacy.html` в корне GitHub не является утверждённой политикой и никогда не должен попадать в публичную CRM-сборку.

## Что требуется от собственника и юриста

Создайте файл **`approved/privacy.html`** (именно это имя/путь) с действительной утверждённой политикой обработки персональных данных для владельца 24bkm.com. Укажите проверенные реквизиты оператора, адрес, контакты, цели и основания обработки заявок, состав данных (имя, телефон, email, компания, маршрут, описание груза, UTM), размещение на Beget, передачу в коробочный Bitrix24, сроки хранения, меры защиты и процедуры отзыва согласия/реализации прав, а также информацию о трансграничной передаче и иных обработчиках — по требованиям применимого законодательства.

Добавьте в `<head>` утверждённой HTML-страницы отдельный **технический маркер выпуска**:

```html
<meta name="bkm-policy-status" content="approved">
```

Этот маркер подтверждает только решение оператора разместить документ, он не заменяет юридическую проверку. Не оставляйте в файле пустые поля, TODO или примерные реквизиты. При подготовке документа учитывайте правила страны регистрации оператора и применимые правила обработки данных посетителей.

После утверждения и проверки можно собрать CRM-вариант:

```bash
BKM_CRM_RELEASE=on python3 scripts/build-production.py
```

Без `approved/privacy.html` или без маркера сборка остановится. Изменять исходный `assets/site-config.js` вручную **не нужно** — производственная сборка включит его только для одобренного выпуска.

**Важно:** ни Bitrix webhook, ни пароль хостинга, ни другие секреты нельзя помещать в этот публичный репозиторий. Секреты хранятся вне `public_html`, в приватной конфигурации Beget.
