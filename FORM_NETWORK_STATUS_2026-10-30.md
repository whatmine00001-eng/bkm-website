# БКМ — тестовая форма и доступность, 30.10.2026

## Форма опубликована, но НЕ отправляет заявки

По просьбе владельца не публиковать пока политику размещена тестовая форма на главной странице, в блоке #contact. Это интерфейс для проверки заполнения; реальный приём персональных данных и отправка в Bitrix24 не включены. Нельзя представлять этот выпуск как завершение интеграции.

Поля: имя, телефон, компания, email, услуга, пункты отправления/назначения, груз и описание задачи. Есть все шесть направлений, в том числе финансовое сопровождение, и «Другое». Кнопки: «Проверить заполнение», «Тестовый пример», «Очистить». Пример содержит только вымышленные данные.

На форме явно указано, что данные не отправляются, а после проверки отображается: «Поля заполнены корректно. Это только тест: заявка не отправлена, лид в Bitrix24 не создан». У полей нет HTML-формы с действием отправки; контейнер role=form, кнопки type=button. Новый код не делает сетевых запросов и не сохраняет значения в хранилищах браузера. Публичный site-config по-прежнему formsEnabled=false, analyticsEnabled=false.

## VPN: диагностика, не подтверждённое исправление

Проверка 41015089094 завершена. Ubuntu и macOS исполнители GitHub Actions находились в США (Azure westus3 и westus), не за пользовательским VPN. Оба получили HTTP 200 от HTTPS-корня с www и без, index.html и services.html. Google и Cloudflare DNS согласованно возвращают 45.130.41.212 для обоих имён. AAAA отсутствуют. Сертификат действителен для обоих имён до 20.01.2027; TLS 1.2 и 1.3, ALPN h2 успешны.

В проверенном .htaccess не обнаружены искомые признаки ограничения по IP/стране/VPN; в двух родительских каталогах .htaccess отсутствует. Внешний firewall Beget и маршрут VPN этим не проверены. Принудительного редиректа корневых HTTP/www-вариантов пока нет; это отдельная настройка, НЕ доказанная причина сбоя VPN.

Название VPN, выбранная страна, точная ошибка и время отказа пока неизвестны. Поэтому не утверждаем, что проблема устранена или сайт доступен из абсолютно любой страны. Не отключали защиту и не меняли DNS наугад. Для точной проверки нужны скрин ошибки, VPN/страна и при необходимости исходящий IP для поддержки хостинга.
