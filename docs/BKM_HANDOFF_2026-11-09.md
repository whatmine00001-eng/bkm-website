# БКМ — передача контекста сайта (9 ноября 2026)

Внутренняя справка для продолжения проекта в новом чате. Не содержит паролей, вебхуков и других секретов.

## Принятые решения
- **Beget — основная площадка**. Cloudflare Pages — временная площадка для непрерывной разработки, пока доступ к Beget восстанавливался.
- Домен `24bkm.com` зарегистрирован в GoDaddy; настройки DNS/MX/Exchange не менять без отдельной проверки. Коробочный Bitrix24 — `https://bitrix.24bkm.com/`.
- GitHub: `whatmine00001-eng/bkm-website`, рабочая ветка Cloudflare `cloudflare/pages-v1`, исходная дизайн-ветка `design/bkm-modern-v1`.
- Временный сайт: `https://bkm-website-7kj.pages.dev/`; облегчённая версия `/lite.html`.
- Пользователь подтвердил обе политики обработки персональных данных, они опубликованы как `privacy.html` и `consent.html`.
- Фирменный стиль: оригинальный логотип БКМ, тёмно-зелёный/графит/оранжевый, сдержанный премиальный вид, слоган **«СЛОЖНОЕ ДЕЛАЕМ ПРОСТЫМ»**.

## Bitrix24 и секреты
- Отправка сайта → Cloudflare Pages Function `functions/api/lead.js` → CRM метод `crm.lead.add`.
- Новый вебхук Bitrix24 был создан пользователем и сохранён в Cloudflare под зашифрованной переменной `BKM_BITRIX_WEBHOOK_URL`. **Никогда не запрашивать или публиковать полный секрет в чате/GitHub.**
- Cloudflare Turnstile через `BKM_TURNSTILE_SECRET` + `BKM_TURNSTILE_SITE_KEY`; серверный `functions/api/form-config.js` показывает только публичную готовность.
- `BKM_CRM_ENABLED=true`; версия согласия `bkm-consent-uploaded-2026-11-06-v1`.
- **Ответственный за все лиды — Кирилл, Bitrix24 ID 7**, установлен в JavaScript Cloudflare и PHP Beget.
- Тесты в GitHub Actions имитируют успешный вызов CRM. Реальный лид для последней версии формы необходимо проверить через обычный браузер с человеком, который проходит Turnstile; не повторять отправку автоматически после таймаута.

## Обновление формы — 9 ноября 2026
По указанию пользователя и менеджера Михаила сделана форма с четырьмя видимыми полями:
1. **Телефон** с отдельным списком стран и кодов (34 страны); только цифры национального номера, ограничение длины для выбранной страны и нормализация E.164 на сервере.
2. **Email** обязательный, поддерживается формат `name@domain.ru`, `name@domain.com` и прочие корректные буквенные домены; валидация браузера и на сервере.
3. **Вид услуги**: «Международная перевозка», «Таможенное оформление», «Логистика и склад», «Агентские услуги», «Другое».
4. **Комментарии** с подсказкой про маршрут, груз, сроки.

Удалены имя, компания, отправка, назначение, характеристики груза отдельными полями, услуги «Сборные грузы», «Экспедирование», «Финансовое сопровождение».
Сохранена отдельная обязательная галочка согласия и Cloudflare Turnstile. Устранён некрасивый перенос текста согласия.

Файлы:
- `index.html` — форма.
- `assets/bkm-form.css` — дополнительные адаптивные стили.
- `assets/lead-form.js` — проверка ввода, подготовка запроса.
- `assets/site-config.js` — выбор API endpoint для PHP/Pages.
- `functions/api/lead.js` — проверка данных на сервере Cloudflare.
- `api/lead.php` — эквивалентные правила для будущего Beget PHP 8.2.
- `cloudflare/build-pages.py`, `scripts/build-production.py` — разные пути сборки.
- `cloudflare/test-lead.mjs` — синтетические тесты.

## Открытые вопросы
1. Сделать **один помеченный служебный тестовый лид** через новую форму после Turnstile и подтвердить в Bitrix24 ответственного ID 7. Не использовать настоящие контакты клиентов в тесте.
2. В утверждённой ранее политике есть фактическое упоминание обязательного поля «имя», а новая форма его не собирает, и email теперь обязательный. Требуется отдельная аккуратная синхронизация текста политики с реально отображаемыми полями; сам утверждённый текст при правке формы не переписывался.
3. Beget остаётся основной площадкой: после проверки восстановления развернуть `_production_release` с PHP 8.2, проверить CRM и только затем обсуждать переключение веб-записей.
4. Доступность Cloudflare из России не гарантирована; из Казахстана временный сайт успешно открывался в проверке 6 ноября.
