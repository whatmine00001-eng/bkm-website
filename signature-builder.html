Редактор письма Outlook · предпросмотр подписи

Как использовать: открой этот конструктор на компьютере, выбери сотрудника и настрой интервалы. Нажми «Скопировать в Outlook», затем вставь Ctrl+V в редактор подписи Outlook.

Для классического Outlook: Файл → Параметры → Почта → Подписи. Если логотип не вставился через браузер, вставь отдельно файл PNG. Папка ZIP содержит HTML и логотип для более надёжной установки.

Конструктор работает без интернета. Введённые данные не отправляются на сервер; настройки по возможности сохраняются в этом браузере.
