## 2. Дополнительные риски, обнаруженные в ходе аудита

1. Ранее обычный push в ветку разработки сразу загружал предварительные файлы на публичный тестовый хостинг. Любая синтаксическая ошибка блокировала деплой, но корректная правка автоматически приводила к публикации.
2. Ранее тестовый rsync включал неутверждённый `privacy.html` и `api/lead.php`; для публичной демонстрации дизайна эти файлы не нужны.
3. Старая ручная задача `.github/workflows/deploy-beget.yml` могла копировать весь исходный репозиторий на другой публичный тестовый адрес.
4. Без подтверждённой политики обработки данных нельзя публиковать работающую CRM-форму и принимать контакты. Флаг `BKM_CRM_RELEASE=off` должен оставаться безопасным значением по умолчанию.
5. Создание лидов в Bitrix24 **пока не проверено end-to-end**. Последняя офлайн-проверка приватного конфига от 27.10.2026 выявила ошибочный суффикс `crm.lead.add.json` в URL. Секретные данные не печатались и запросы в CRM не отправлялись: [40501015778](https://github.com/whatmine00001-eng/bkm-website/actions/runs/40501015778).
6. PR #1 нельзя автоматически считать готовым к слиянию: его совместимость с `main` требует отдельной проверки конфликтов и ревью.

## 3. Точечные исправления

- `.github/workflows/publish-beget-preview.yml` (ветка разработки): **каждый push запускает только CI**, никакого SSH и выгрузки файлов. Тестовая публикация допускается только через явный `workflow_dispatch` на ветке `design/bkm-modern-v1`; checkout привязан к точному SHA проверяемого коммита.
- `scripts/build-preview.py`: отдельная демонстрационная сборка; 16 страниц сохраняют `noindex,nofollow` и получают `robots.txt: Disallow: /`; вёрстка формы остаётся видимой, но сам тег `<form>` заменён на неотправляющий `<div>`, поля и кнопки отключены. Черновик политики, PHP API и активный JS формы исключены.
- **Уже опубликованная 26.10 тестовая папка ещё не обновлена** этим новым кодом: push-коммиты выполняют только CI. При следующем явном ручном тестовом деплое workflow загрузит `_preview_release` и удалит из изолированной тестовой папки устаревшие `privacy.html` и `api/lead.php`. До такого деплоя нельзя считать ранее опубликованный тестовый URL очищенным.
- Старый `deploy-beget.yml` в ветке разработки отключён, а запуск preview-workflow из `main` заменён на информационную задачу без выгрузки.
- `scripts/test_lead_safety.py`: автономно проверяет, что PHP-обработчик отвергает GET, HTTP, чужой `Host`, чужой `Origin`, неверный `Content-Type` и пустые запросы. Данные клиентов и реальные CRM API не используются.
- `scripts/check-crm-config.php --format-only`: офлайн-проверка наличия приватного файла, формата URL вебхука, `rate_salt` и выключенных флагов. Этот режим заканчивается **до любых HTTP-запросов** в Bitrix24.
- `.gitignore` исключает локальные release-директории и приватные конфигурации.
